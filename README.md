# Обработка изображений: практика 2. Наложение и удаление шума

Решение ДЗ 2 на радарном снимке `sar_1.jpg`: зашумить изображение гауссовым и постоянным (равномерным) шумом, протестировать фильтры с разными параметрами и выяснить, какой справляется лучше.

## Что сделано
1. Два типа шума по модели из лекции `f = s + n`: гауссов и постоянный (равномерный). Каждый в двух вариантах: неотрицательный (как в шаблоне и `notes.docx`) и знакопеременный с нулевым средним.
2. Четыре фильтра с сетками параметров: медианный, Гаусса, билатеральный, нелокальных средних (всего 46 комбинаций на каждый вид шума).
3. Оценка по MSE, SSIM и PSNR относительно чистого изображения, визуальное сравнение на увеличенном фрагменте, графики зависимости качества от параметров.
4. Проверка устойчивости на 5 новых реализациях шума.

## Итог
Для постоянного шума и гауссова шума с нулевым средним лучший фильтр Гаусса (`sigma = 1`). Для гауссова неотрицательного шума лучший билатеральный фильтр (`d = 3`, `sigmaColor = 75`). Подробные таблицы и выводы в последних ячейках ноутбука.
